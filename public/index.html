🔐 Enkripsi Identitas AES-256-GCM

Seluruh data identitas pelapor (Nama, NIK, Email, No. HP) dienkripsi menggunakan algoritma AES-256-GCM sebelum tersimpan di database. Kunci enkripsi disimpan terpisah di server. Hanya Admin yang dapat mendekripsi data tersebut.

🎫 Nomor Tiket Unik Kriptografis

Setiap laporan mendapatkan token unik format WBS-PDG-YYYYMMDD-XXXXXX yang dibuat menggunakan crypto.getRandomValues() browser — jauh lebih aman dari random biasa. Token ini digunakan pelapor untuk melacak status kapan saja 24/7.

⚠️ Indikator Warna Badge SLA

Sistem otomatis menghitung sisa hari kerja menuju batas SLA. Badge HIJAU = tepat waktu, KUNING = jatuh tempo hari ini, MERAH = sudah terlambat. Lihat di kolom "Batas SLA" pada tabel pengaduan.

📱 Aksesibilitas 24/7 Browser & Mobile

Sistem WBS ini dapat diakses kapan saja, 24 jam sehari 7 hari seminggu, melalui browser desktop maupun perangkat mobile (smartphone & tablet). Tampilan responsif penuh dengan breakpoint 1024px, 768px, dan 480px.
